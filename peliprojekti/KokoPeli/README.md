# Pelistä

Haaksirikkouduit saarelle! Ympärrilläsi on erinlaisia esineitä\
Tehtäväsi on löytää reitti pois saarrelta esineiden avulla. Voit kantaa vain 3 esinettä keralla.\
Huomaat että saarelle on ajautunut myös roskaa.\
Kerää roskat saadaksesi pisteitä\

# Toiminnot pelin sisällä

## 1. Tutki huonetta

Kertoo mitä esineitä ja paljonko roskaa huoneessa on. Kertoo myös mahdollisest siirtymät.

## 2. kerää esine

Näyttää eri vaihtoehdot esineille ja antaa pelaajan valita minkä siirtää reppuun.

## 3. Pudota esine

Näyttää eri vaihtoehdot esineille ja antaa pelaajan valita minkä siirtää repusta maahan.

## 4. Siirry huoneeseen

Antaa pelaajan valita mihin huoneeseen siirtyy.

## 5. Kerää roska

Kerää roskan huoneesta. Pelaaja saa siitä pisteen

## 6. Näytä esineet ja pisteet

Näyttää kaikki pelaajan esineet repussa ja kaikki pisteet.

## 7. Ohjeet

Näyttää ohjeet

## 9. Lopeta peli

sulkee ja tallentaa pelin.


# Reitit ja esineet

Ranalla on 7 esinettä.
Tarvitset tietyn seuraavista esineistä edetäksesi huoneesee:
- Taskulamppu
- köysi
- Veitsi
- Kumivene
- tikapuut
- Laskuvarjo
- Bensa

## reitti 1
ranta -> luola -> rotko -> helikopteri

Tarvitset luolaan taskulampun\
Rotkon ylittämiseen tarrvitset köyden.\
Helikopteriin tarvitset bensaa.\


## reitti 2
ranta -> viidakko -> joki -> helikopteri

Tarvitset veitsen viidakkon\
Joen ylittämiseen tarvitset kumiveneen\
Helikopteriin tarvitset bensaa.\


## rreitti 3
ranta -> vuori -> vesiputous -> helikopteri

Tarvitset vuoren kiipeämiseen tikapuut\
Vesiputouksen ylitykseen tarrvitset laskuvarjon.\
Helikopteriin tarvitset bensaa.\
